# こつこつ (Kotsukotsu) — приложение для изучения японского (N5–N4)

«こつこつ» — «понемногу, но упорно»: ровно про то, как устроено приложение.

Настольное приложение для подготовки к JLPT: интервальные повторения (FSRS),
справочники грамматики / кандзи / слов, короткие тексты с вопросами на понимание,
адаптивный вступительный тест, экран прогресса. Работает офлайн.

Стек: React + TypeScript + Vite, оболочка — Electron. Вся учебная логика в
платформенно-независимом слое (`src/`), что оставляет задел на сборку под Android
(Capacitor) из той же кодовой базы.

## Установка (Windows)

Скачайте установщик со страницы [Releases](https://github.com/Nqam/jlpt-app/releases/latest)
(`Kotsukotsu Setup <версия>.exe`) и запустите его.

Установщик не подписан, поэтому SmartScreen покажет предупреждение
«Windows защитила ваш компьютер» → **Подробнее** → **Выполнить в любом случае**.

Прогресс хранится в отдельной базе `user.db` в папке данных приложения и
**не затрагивается** при установке новой версии. Раз в неделю приложение
автоматически кладёт резервную копию в `<userData>/backups/`; вручную —
кнопки экспорт/импорт в Настройках (формат совместим между машинами).

Проверить наличие новой версии: **Настройки → Обновления → Проверить обновления**.

## Разработка

```bash
npm install
npm run build-content   # собирает resources/content.db из локального content/
npm run dev             # запускает приложение в режиме разработки
npm test                # Vitest (ядро, хранилище, UI)
npm run test:e2e        # Playwright (Electron)
npm run build:desktop:installer   # -> dist/Kotsukotsu Setup <версия>.exe
```

### Учебный контент

Курируемый учебный контент (`content/**`) и собранная база `resources/content.db`
**не входят в этот репозиторий** — они распространяются только в составе готового
установщика и предназначены для личного некоммерческого использования. Поэтому
`npm run build-content` без исходных файлов контента создаст пустую базу; сам код
приложения при этом полностью рабочий.
