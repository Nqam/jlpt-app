# Дизайн: план 4c-2 — раздел «Тексты»

## 1. Контекст

Дизайн-спека `2026-09-03-jlpt-desktop-app-design.md` §7 описывает экран «Тексты»:
короткие тексты по уровню, тап по слову — разбор, вопросы на понимание после текста.
Сейчас `/texts` не существует вообще.

**Источник контента**: Tadoku (tadoku.org, Level 0/1) — CC BY-NC-ND, только личное
некоммерческое использование (явное решение пользователя — не для публикации/продажи).
Атрибуция в `content/CREDITS.md`, как у остальных источников.

**Не в объёме v1** (согласовано): разбор по тапу на произвольное слово — требует
сегментации японского текста на слова (нет пробелов), которой в проекте нет вообще —
отдельная большая задача, не в этом плане. Тексты НЕ часть SRS/ежедневной очереди —
самостоятельный раздел, как «Прогресс», без FSRS-карточек.

## 2. Контент

`content/texts/<level>/<id>.md`, авторский Markdown (по образцу грамматики):

```markdown
---
id: n5-momotaro
level: N5
title: 桃太郎
---

## Текст

<японский текст, фуригана в формате кандзи[чтение], как у грамматики>

## Перевод

<русский перевод>

## Вопросы

### Вопрос 1
<текст вопроса>
- [ ] <неверный вариант>
- [x] <правильный вариант>
- [ ] <неверный вариант>
- [ ] <неверный вариант>

### Вопрос 2
...
```

3-4 вопроса на текст, ровно один `[x]` на вопрос (валидируется). Схема БД (новые
таблицы `texts`/`text_questions`), парсер `scripts/build-content/parse-texts.ts` —
по образцу `parse-grammar.ts`.

## 3. Экраны

- `/texts` — список по уровню (как `VocabListScreen`), значок «прочитано» у
  завершённых.
- `/texts/:id` — японский текст (фуригана — общая настройка `furigana_enabled`),
  кнопка «Показать перевод», затем вопросы на понимание один за другим (простой
  выбор из 4, без переиспользования `QuestionView`/`grade` — те завязаны на
  `Question`/`itemType` из quiz-engine, вопросы на понимание текста — другая по
  смыслу и данным сущность). По завершении — id текста добавляется в новый
  setting `texts_read_ids: string[]` (тот же паттерн, что `placement_marked_ids`).
- `Nav.tsx` получает пункт «Тексты» (простое добавление в существующий плоский
  список назначений, как Кандзи/Слова).

## 4. Не в объёме

Разбор слова по тапу; переозвучка/TTS; тексты в SRS-очереди; N3-N1 тексты (только
данные, не код, как и весь остальной контент).
