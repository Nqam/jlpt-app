# План 4d: Android-оболочка (Capacitor) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить вторую платформенную оболочку (Android, через Capacitor) поверх
существующего веб-ядра приложения «Kotsukotsu», не трогая ядро/UI — только новая
реализация `PlatformAdapter` и сборочный конвейер, дающие подписанный sideload-APK.

**Architecture:** `PlatformAdapter` (уже существующий интерфейс, `src/platform/adapter.ts`)
получает вторую реализацию `src/platform/android.ts` поверх Capacitor-плагинов
(`Filesystem`/`Share`/`Browser`) вместо Electron IPC. Веб-бандл для Android собирается
отдельным plain-Vite конфигом (не electron-vite) и отдаётся Capacitor'ом через
`https://localhost`, поэтому `content.db`/`sql-wasm.wasm` читаются обычным `fetch`, а не
через мост, как на десктопе. Нативный Capacitor-проект живёт в `shells/android/`
(тот же паттерн, что `shells/electron/`).

**Tech Stack:** Capacitor (core + android + cli), `@capacitor/filesystem`,
`@capacitor/share`, `@capacitor/browser`, существующие React/TS/Vite/sql.js/ts-fsrs
ядро без изменений, Vitest + Playwright (браузерная ширина, без эмулятора).

**Spec:** `docs/superpowers/specs/2026-09-11-plan-4d-android-design.md` (и общая
`docs/superpowers/specs/2026-09-03-jlpt-desktop-app-design.md`, §8–9).

## Global Constraints

- `minSdk` 26, `targetSdk` — актуальный на момент сборки (см. спеку §5).
- Ядро (`src/core/**`) и UI (`src/ui/**`, кроме `Nav.tsx` в задаче 2) не меняются —
  вся платформенная разница инкапсулирована в `PlatformAdapter`.
- `src/**` не импортирует Node/Electron API напрямую (eslint `no-restricted-imports`,
  `eslint.config.js`) — Capacitor-плагины разрешены (браузерный код, не Node).
- TTS не реализуется (исключён из объёма приложения целиком, план 4c-1).
- Импорт бэкапа user.db делается уже в v1 (не откладывается на v1.1 — правка
  исходного плана, см. спеку §3).
- Постоянный keystore хранится вне git-репозитория; в репо — только
  `*.example`-шаблон конфигурации подписи (спека §5).
- Версия приложения (`versionName`) — из `package.json`, единая с десктопом.
- Тесты: `tests/**/*.test.{ts,tsx}` через Vitest (`environment: 'node'` по умолчанию,
  `jsdom` — по `environmentMatchGlobs` в `vitest.config.ts`); e2e — Playwright, ширина
  окна вместо реального устройства (эмулятор не используется, см. спеку §6).

```ts
/**
 * Разрешён ли внешний URL к открытию в браузере / переходу.
 *
 * Только `https:` и только на `github.com` (или его поддоменах) — приложение
 * ведёт наружу лишь на страницу релизов и репозиторий. Всё остальное (в том
 * числе `http:`, `file:`, произвольные хосты) отклоняется — защита от подмены
 * ссылки через контент или скомпрометированный рендерер.
 */
export function isSafeExternalUrl(raw: string): boolean {
  let u: URL;
  try {
    u = new URL(raw);
  } catch {
    return false;
  }
  if (u.protocol !== 'https:') return false;
  return u.hostname === 'github.com' || u.hostname.endsWith('.github.com');
}
```

```tsx
import { useEffect, useState } from 'react';
import { NavLink } from 'react-router-dom';

const DESTINATIONS = [
  { to: '/', label: 'Сегодня', icon: '🗓' },
  { to: '/grammar', label: 'Грамматика', icon: '📘' },
  { to: '/kanji', label: 'Кандзи', icon: '㊗' },
  { to: '/vocab', label: 'Слова', icon: '📝' },
  { to: '/course', label: 'Курс', icon: '📚' },
  { to: '/texts', label: 'Тексты', icon: '📖' },
  { to: '/progress', label: 'Прогресс', icon: '📈' },
];

function useIsWide(breakpoint = 768): boolean {
  const [wide, setWide] = useState(() => window.innerWidth >= breakpoint);
  useEffect(() => {
    const onResize = () => setWide(window.innerWidth >= breakpoint);
    window.addEventListener('resize', onResize);
    return () => window.removeEventListener('resize', onResize);
  }, [breakpoint]);
  return wide;
}

function NavLinks({ onNavigate }: { onNavigate?: () => void }) {
  return (
    <>
      {DESTINATIONS.map((d) => (
        <NavLink key={d.to} to={d.to} end={d.to === '/'} className="nav-link" onClick={onNavigate}>
          <span className="nav-icon" aria-hidden>{d.icon}</span>
          <span className="nav-label">{d.label}</span>
        </NavLink>
      ))}
      <NavLink to="/settings" className="nav-link nav-link--settings" onClick={onNavigate}>
        <span className="nav-icon" aria-hidden>⚙</span>
        <span className="nav-label">Настройки</span>
      </NavLink>
    </>
  );
}

export function Nav() {
  const wide = useIsWide();
  const [open, setOpen] = useState(false);

  useEffect(() => {
    if (wide) setOpen(false);
  }, [wide]);

  if (wide) {
    return (
      <nav data-variant="sidebar" className="nav">
        <NavLinks />
      </nav>
    );
  }

  return (
    <>
      <button
        type="button"
        className="nav-drawer-toggle"
        aria-label="Меню"
        aria-expanded={open}
        onClick={() => setOpen((v) => !v)}
      >
        ☰
      </button>
      {open && <div className="nav-drawer-backdrop" onClick={() => setOpen(false)} />}
      <nav data-variant="drawer" className={`nav${open ? ' nav--open' : ''}`}>
        <NavLinks onNavigate={() => setOpen(false)} />
      </nav>
    </>
  );
}
```

- [ ] **Step 4: Создать `scripts/copy-android-assets.ts`**

Копирует `resources/content.db` (результат `build-content`) и wasm-модуль sql.js в
`public/`, откуда Vite сам подхватит их в корень `out/android` (статические файлы

```ts
import { mkdir, copyFile } from 'node:fs/promises';
import { createRequire } from 'node:module';
import { resolve } from 'node:path';

const require = createRequire(import.meta.url);

async function main(): Promise<void> {
  const publicDir = resolve(__dirname, '../public');
  await mkdir(publicDir, { recursive: true });
  await copyFile(
    resolve(__dirname, '../resources/content.db'),
    resolve(publicDir, 'content.db'),
  );
  await copyFile(
    require.resolve('sql.js/dist/sql-wasm.wasm'),
    resolve(publicDir, 'sql-wasm.wasm'),
  );
  console.log('android assets copied to public/');
}

main().catch((e) => {
  console.error(e);
  process.exit(1);
});
```

- [ ] **Step 4: Реализовать `src/platform/android-codec.ts`**

`btoa`/`atob` работают строго с "бинарной строкой" (по одному символу на байт) —
конвертация через `String.fromCharCode` на весь буфер разом упирается в лимит
аргументов движка на больших файлах, поэтому идём чанками.

```ts
const CHUNK = 8192;

/** Байты → base64. Чанками — `String.fromCharCode(...bytes)` падает на больших массивах. */
export function uint8ToBase64(bytes: Uint8Array): string {
  let binary = '';
  for (let i = 0; i < bytes.length; i += CHUNK) {
    binary += String.fromCharCode(...bytes.subarray(i, i + CHUNK));
  }
  return btoa(binary);
}

/** base64 → байты. */
export function base64ToUint8(b64: string): Uint8Array {
  const binary = atob(b64);
  const bytes = new Uint8Array(binary.length);
  for (let i = 0; i < binary.length; i++) bytes[i] = binary.charCodeAt(i);
  return bytes;
}
```

```ts
        document.body.appendChild(input);
```

```ts
    async checkForUpdate(): Promise<{ latest: string; url: string } | null> {
      if (!GITHUB_REPO) return null;
      try {
        const res = await fetch(`https://api.github.com/repos/${GITHUB_REPO}/releases/latest`, {
          headers: { Accept: 'application/vnd.github+json' },
          signal: AbortSignal.timeout(8000),
        });
        if (!res.ok) return null;
        const body = (await res.json()) as { tag_name?: string; html_url?: string };
        if (!body.tag_name || !body.html_url) return null;
        return { latest: body.tag_name, url: body.html_url };
      } catch {
        return null;
      }
    },
    async openExternal(url: string): Promise<void> {
      if (isSafeExternalUrl(url)) await Browser.open({ url });
    },
  };
}
```

```ts
import { Capacitor } from '@capacitor/core';
import type { PlatformAdapter } from './adapter';
import { createDesktopAdapter } from './desktop';
import { createAndroidAdapter } from './android';

let cached: PlatformAdapter | null = null;

/** Единая точка получения платформенного адаптера. */
export function getPlatformAdapter(): PlatformAdapter {
  if (cached) return cached;
  cached = Capacitor.isNativePlatform() ? createAndroidAdapter() : createDesktopAdapter();
  return cached;
}

export type { PlatformAdapter };
```
