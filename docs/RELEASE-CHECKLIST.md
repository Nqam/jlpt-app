# Чек-лист релиза десктопа (ручной)

Область: только Windows-десктоп, план 1. Android/Capacitor — следующий план, здесь не рассматривается.

Версия берётся из `package.json` (`version`). Перед релизом при необходимости поднять её там.

## Сборка

- [ ] `npm ci` — чистая установка зависимостей
- [ ] `npm run build-content` — `resources/content.db` пересобран из курируемого Markdown
- [ ] `npm run typecheck` — без ошибок
- [ ] `npm test` — vitest зелёный (42; `pretest` сам пересобирает `resources/content.db`)
- [ ] `npm run test:e2e` — Playwright зелёный (smoke 2 + grammar-browse 2; `packaged.spec.ts` прогоняется только если рядом лежит `dist/win-unpacked`)
- [ ] `npm run build:desktop:installer` — собирает установщик

  Скрипт сам делает `build-content` → `build` (`electron-vite build`) → `electron-builder --win`.
  Результат: `dist/JLPT Setup <версия>.exe` (NSIS, x64) + `.blockmap`.

  Первый запуск `electron-builder` на чистой машине качает вспомогательные бинарники
  (`winCodeSign` ~5 МБ, `nsis` ~1.3 МБ, `nsis-resources` ~0.7 МБ) с
  `github.com/electron-userland`. Это штатно, нужен доступ в интернет.

  На неповышенном shell Windows без Developer Mode первая упаковка может упасть при
  распаковке `winCodeSign*.7z` (внутри архива — символические ссылки для macOS).
  Включите Developer Mode или запустите первый `build:desktop:installer` из
  консоли с правами администратора.

### Проверка содержимого пакета

- [ ] `dist/win-unpacked/resources/content.db` присутствует
- [ ] `dist/win-unpacked/resources/sql-wasm.wasm` присутствует

  Оба кладутся через `extraResources` в `electron-builder.yml`. Упакованный
  Electron main читает их из `process.resourcesPath` (см. `shells/electron/main.ts`).
  Если какого-то файла нет — приложение покажет «Не удалось загрузить учебную базу».

## Дымовой тест (Windows)

- [ ] Установщик запускается, предлагает выбрать каталог установки (oneClick=false)
- [ ] Устанавливается без прав администратора (perMachine=false, в профиль пользователя)
- [ ] Ярлык «JLPT» в меню Пуск и на рабочем столе
- [ ] Приложение открывается, показывает оболочку, тема переключается (светлая/тёмная)
- [ ] Грамматика: список N5 (8 пунктов), открывается карточка, видна фуригана, работают связанные пункты
- [ ] Поиск по списку грамматики фильтрует пункты
- [ ] Узкое окно (< 768px) → нижняя навигация; широкое → боковая
- [ ] Переустановка поверх (тот же или новый установщик) — приложение открывается
- [ ] Удаление через «Приложения и возможности» — исполняемые файлы и ярлыки убираются

## Данные пользователя

- В плане 1 пользовательских данных нет (`user.db` появится в следующем плане).
- Когда появится: `user.db` будет жить в каталоге Electron `userData` —
  `%APPDATA%\JLPT\` (вне каталога установки). Поэтому переустановка и обновление
  приложения его **не трогают** — прогресс сохраняется.
- Поставляемый `content.db` — read-only, всегда перезаписывается новой версией при установке.

## Откат

- Отдельного механизма отката нет. Откат = удалить текущую версию и поставить
  предыдущий установщик `JLPT Setup <старая версия>.exe` (хранить прошлые артефакты).
- `%APPDATA%\JLPT\` при этом не затрагивается, так что будущие пользовательские
  данные переживут откат.

## Известные ограничения версии

- Только справочник грамматики N5 (8 пунктов). Кандзи, слова, тексты, прогресс,
  SRS, вступительный тест — заглушки/отсутствуют.
- Установщик не подписан (нет code signing). Windows SmartScreen покажет
  предупреждение «неизвестный издатель» — это ожидаемо для неподписанной сборки.
- Только Windows x64.
